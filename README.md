# 🎮 Rock Paper Scissors - React Game

An interactive Rock-Paper-Scissors game built using React.js. This project demonstrates component-based architecture, state management, and dynamic UI updates.

---

## 🚀 Features

- 🎯 Play Rock, Paper, Scissors against the computer
- ⚡ Real-time result display
- 🔁 Random computer choice generation
- 🧠 Game logic implementation (win/lose/draw)
- 🎨 Clean and responsive user interface

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
